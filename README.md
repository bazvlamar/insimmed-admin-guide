# Інструкція адміністратора сайту ІНСІММЕД

Статична сторінка-інструкція для адміністратора сайту [insimmed.org.ua](https://insimmed.org.ua): вхід, заходи БПР, новини, сторінки, англійська версія, документи провайдера, електронний курс, звіт для БПР в Excel, сертифікати.

Опублікована через GitHub Pages. Щоб оновити — змініть `index.html` і зробіть коміт у гілку `main`.
